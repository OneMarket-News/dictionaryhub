SourceRoot records these tag-pinned statements component by component; it does
not assert a broader territorial or global legal conclusion.

This Greek edition is not described as the source text underlying the KJV.
Original-language source text and source morphology do not establish one
objectively correct English translation. Lexical interpretation, translation,
commentary, theology, textual variants, and project inference are excluded.
