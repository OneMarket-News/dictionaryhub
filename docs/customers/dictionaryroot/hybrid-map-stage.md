# DictionaryRoot Customer #001 - Hybrid Knowledge Map

This stage combines the original radial knowledge-map experience with the modern live SourceRoot customer integration.

## Customer-visible changes

- Map Mode is the default radial exploration experience.
- Readable Mode preserves the structured card view.
- The selected concept panel can be hidden to give the map more room.
- Exact Open English WordNet lemmas are searchable, even when a synset uses a different canonical title.
- Multiple exact word senses are presented for customer selection rather than opening a fuzzy match automatically.
- Search-selected lemmas remain visible as the center label while SourceRoot preserves the canonical synset identity underneath.

## SourceRoot contract change

The node search record now preserves node metadata and includes lexical lemmas in searchable text and ranking. This is a reusable requirement discovered during Customer #001 onboarding.
