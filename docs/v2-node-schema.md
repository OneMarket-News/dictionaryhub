# SourceRoot V2 Node Schema

This schema defines what a high-quality SourceRoot concept should contain.

## Purpose

SourceRoot V2 improves the quality of the knowledge inside the system.

A V2 concept should not only define a word. It should explain:

- What the concept means
- Why it matters
- Where it came from
- What supports it
- What it connects to
- Why those relationships exist
- How the entry has changed
