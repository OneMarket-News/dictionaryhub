# Rejected candidate sources

## John Gill's Exposition of the Entire Bible

Rejected for v1. The underlying historical work is old enough to be public
domain, but no candidate artifact inspected for this stage established both a
clean machine-readable transcription identity and unambiguous redistribution
terms from an acceptable provider. The main CrossWire repository has no Gill
module; a separately hosted raw package did not provide sufficient transcription
rights evidence. Commercial Bible platforms and unattributed conversions were
not scraped or substituted. No Gill text is included.

The resulting two-work corpus remains coherent for the four bounded passages.
It is not described as comprehensive, representative, balanced, or authoritative.
