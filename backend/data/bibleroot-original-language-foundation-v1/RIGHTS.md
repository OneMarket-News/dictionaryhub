# BibleRoot Original-Language Rights Components

Rights are recorded per physical-artifact component in
`rights-components.json`; no artifact-wide status is substituted for that
matrix.

For each OSHB XML artifact:

- Westminster Leningrad Codex source text: the tag-pinned project documentation
  states that it is in the public domain.
- OSHB lemma and morphology work: CC BY 4.0.
- Required attribution: Original work of the Open Scriptures Hebrew Bible
  available at https://github.com/openscriptures/morphhb

For `Nestle1904.csv`, separate records cover the printed edition, digital
transcription, morphology, lemmatization, Strong's-number data, and repository
markup/formatting. Each record says only that the `rel-1-3` README places the
total work in the Public Domain. SourceRoot records that pinned project
statement and does not make a broader independent or global legal conclusion.

Source text, source analysis, lexical interpretation, translation, commentary,
theological interpretation, and SourceRoot inference remain distinct layers.
