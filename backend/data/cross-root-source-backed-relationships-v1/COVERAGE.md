# Exact corpus coverage

The production corpus contains 143 released HistoryRoot assertions and 178 independently inspectable evidence records. It has 101 distinct subject resources, 76 distinct object resources, 280 total reused registry resources (including source-record resources), and zero additions. All 143 assertions are same-Root HistoryRoot assertions; cross-Root semantic assertions are zero.

All assertions are `directly_sourced`, `active`, `unreviewed`, uncertain, and not disputed. None are marked `accepted_after_review`: the released source statuses `pilot-review-required` and `corpus-review-ready` prove publication availability but not completed semantic review. There are 22 causal and 121 non-causal assertions.

Excluded-record counts are zero for drafts, rejected records, private records, missing endpoints, missing provenance, and unsupported predicates because no such record enters the released candidate collection.
