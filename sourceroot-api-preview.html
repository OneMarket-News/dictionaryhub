SourceRoot API Preview

A prototype view of how SourceRoot could expose nodes, assertions, edges, sources, search, citations, and revisions through an API layer. This is not a live backend yet. It is the product contract for what the engine is becoming.

API Purpose

SourceRoot’s API would let apps, AI systems, search tools, partner companies, and future hubs retrieve structured knowledge with provenance. The key idea is simple: every answer should be traceable back to nodes, assertions, relationships, sources, and revisions.

Application / AI / Partner Tool ↓ SourceRoot API ↓ Search → Nodes → Assertions → Edges → Sources → Citations ↓ Verified, inspectable, source-aware knowledge

Core Endpoints

GET /nodes

List Universal Nodes

Returns concept, phrase, symbol, external entity, or business-document nodes from all connected hubs.

id title type domain summary sourceIds
Example response 
{
  "nodes": [
    {
      "id": "wikidata-light",
      "title": "Light",
      "type": "Wikidata Item",
      "domain": "Wiki",
      "summary": "Structured public entity record for light.",
      "sourceIds": ["wikidata-q9128"]
    }
  ]
}
GET /nodes/:id

Get One Node

Returns a full node inspection payload, including assertions, incoming relationships, outgoing relationships, sources, and revisions.

node assertions outgoingEdges incomingEdges sources revisions
Example response 
{
  "node": {
    "id": "bible-symbol-light",
    "title": "Light",
    "domain": "BibleRoot"
  },
  "assertions": [],
  "outgoingEdges": [],
  "incomingEdges": [
    {
      "id": "wikidata-light-same-as-bible-light",
      "fromNodeId": "wikidata-light",
      "toNodeId": "bible-symbol-light",
      "relationshipType": "SAME_AS_RELATED_CONCEPT"
    }
  ],
  "sources": [],
  "revisions": []
}
GET /assertions

List Assertions

Returns claims, definitions, summaries, explanations, examples, symbolic meanings, and external statements attached to nodes.

id nodeId assertionType label body confidence sourceIds
Example response 
{
  "assertions": [
    {
      "id": "wikidata-assertion-light-description",
      "nodeId": "wikidata-light",
      "assertionType": "wikidata-description",
      "label": "Wikidata Description",
      "body": "electromagnetic radiation at or near visible wavelengths",
      "confidence": "community-maintained",
      "sourceIds": ["wikidata-q9128"]
    }
  ]
}
GET /edges

List Relationships

Returns same-hub and cross-hub relationships between nodes, including relationship type, summary, and supporting sources.

id fromNodeId toNodeId relationshipType domain sourceIds
Example response 
{
  "edges": [
    {
      "id": "wikidata-light-relates-to-dictionary-truth",
      "fromNodeId": "wikidata-light",
      "toNodeId": "dictionary-truth",
      "relationshipType": "RELATES_TO",
      "domain": "Wiki",
      "sourceIds": ["wikidata-q9128"]
    }
  ]
}
GET /sources

List Sources

Returns provenance records used by nodes, assertions, and relationships. This is the core of SourceRoot’s trust layer.

id name domain type publisher license url
Example response 
{
  "sources": [
    {
      "id": "wikidata-q9128",
      "name": "Wikidata — Light (Q9128)",
      "domain": "Wiki",
      "type": "Structured Knowledge Graph",
      "publisher": "Wikimedia Foundation / Wikidata contributors",
      "license": "CC0 public domain dedication",
      "url": "https://www.wikidata.org/wiki/Q9128"
    }
  ]
}
GET /search?q=light

Search SourceRoot

Searches across nodes, assertions, edges, and sources. Future versions could rank by credibility, citation usage, recency, and domain.

query nodes assertions edges sources
Example response 
{
  "query": "light",
  "results": {
    "nodes": [
      "wikidata-light",
      "bible-symbol-light"
    ],
    "assertions": [],
    "edges": [
      "wikidata-light-same-as-bible-light"
    ],
    "sources": [
      "wikidata-q9128"
    ]
  }
}
POST /citations

Log Citation Event

Records when an app, AI, user, or partner cites a source-backed assertion. This becomes the future citation economy layer.

citationId sourceId assertionId consumerId timestamp usageType
Example request 
{
  "consumerId": "ai-assistant-example",
  "nodeId": "wikidata-light",
  "assertionId": "wikidata-assertion-light-description",
  "sourceId": "wikidata-q9128",
  "usageType": "answer-citation",
  "context": "User asked what light means across public data and symbolic sources."
}
GET /revisions

List Revisions

Returns change history for nodes, assertions, edges, and sources so knowledge can be audited over time.

revisionId objectId objectType summary changedAt changedBy
Example response 
{
  "revisions": [
    {
      "revisionId": "rev-wikidata-light-0-1",
      "objectId": "wikidata-light",
      "objectType": "node",
      "summary": "Initial manual WikidataRoot sample based on Wikidata item Q9128.",
      "changedAt": "prototype",
      "changedBy": "SourceRoot build"
    }
  ]
}

How an AI Would Use SourceRoot

1. Identify Query The AI detects the user is asking about a concept, source, relationship, or claim.
2. Search Nodes It searches SourceRoot for matching nodes across DictionaryHub, BibleRoot, Wiki, and future hubs.
3. Retrieve Assertions It pulls definitions, statements, explanations, examples, and symbolic meanings.
4. Check Sources It verifies which sources support each assertion and whether those sources have licenses or credibility metadata.
5. Follow Edges It follows relationships to related concepts, supporting nodes, opposing views, or cross-domain meanings.
6. Cite and Log It cites the source-backed assertion and can log a citation event for credit, audit, or payment.
