Import Bundle Preview

Routable bundle controls are generated directly from the SourceRoot bundle registry. The validator does not import data yet. It only previews whether the selected bundle is structurally safe.

Validation Issues

Errors block import. Warnings allow preview but signal that the bundle needs review.

Staging Summary

A bundle can be staged only after it passes structural validation. Staging is stored locally in this browser and does not write to a database.

Load and validate a bundle to review its staging summary.
