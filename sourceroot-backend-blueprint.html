Implemented Alpha Architecture

SourceRoot now runs as one TypeScript REST API service backed by PostgreSQL. Import bundles are validated at the API boundary, normalized into relational graph tables, and remain retrievable through bundle-scoped and registry endpoints.

Frontend

HTML/JavaScript pages now call the live API for imports, registries, inspection, search, graphs, and dashboard counts.

API

Implemented Node.js + TypeScript + Express REST service.

Database

Implemented PostgreSQL persistence with normalized graph records and bundle tracking.

Authentication

Not yet implemented. Managed identity or secure session authentication remains the next protection boundary.

Deployment

Still local development. Production hosting, managed PostgreSQL, environment configuration, monitoring, and backups remain.

Architecture decision confirmed: the single-service REST and PostgreSQL approach is working. Microservices, blockchain storage, graph databases, and multiple databases remain unnecessary at the current scale.

Architecture Decisions

DecisionRecommendationReason
API styleREST firstMaps directly to current lifecycle operations and is easier to test than introducing GraphQL immediately.
Backend languageTypeScriptMatches the browser JavaScript model while adding types and safer schema contracts.
DatabasePostgreSQLStrong foreign keys, transactions, JSONB, full-text search, and mature hosting.
Graph storageRelational edge tableThe graph is still modest. A dedicated graph database would add complexity without current benefit.
ArtifactsStore exact JSON plus normalized rowsPreserves portability and auditability while enabling search and joins.
ValidationShared rules, server executionThe server must become the authority while the browser remains a fast preview.
Audit historyAppend-only lifecycle eventsMatches the browser model and protects provenance.
Hub extensionsJSONB firstHistoryRoot and future hubs can evolve before dedicated extension tables are stable.

Service Boundaries

Validation Service

Implemented backend schema checks, controlled vocabularies, references, counts, readiness, and validation issues.

Import and Bundle Service

Implemented validation, normalized import, bundle listing, bundle retrieval, and bundle-scoped registry reads.

Legacy Package Service

Browser-local package creation and restoration remain legacy tooling and are not part of the current PostgreSQL workflow.

Review Service

Not yet implemented server-side. Future work includes approvals, rejections, review notes, and revision decisions.

Audit Event Service

Planned append-only server-side audit history for imports, reviews, revisions, and permission-sensitive writes.

Knowledge Query Service

Implemented node, assertion, edge, source, revision, node-detail, bundle-scoped, and unified search endpoints.

These are code-level modules inside one application at first—not separately deployed services.

Database Model

The implemented database currently stores imported bundles, nodes, assertions, edges, sources, revisions, and source-link join tables. Users, roles, reviews, lifecycle events, and hub-specific workflow tables remain future migrations.

Extensibility

Domain adapters and bundle metadata preserve cross-hub structure while dedicated hub tables remain optional.

Every uploaded bundle and package should preserve its original JSON, even after its objects are normalized into relational rows.

Authentication and Authorization

RoleCapabilities
ReaderRead approved public nodes, assertions, sources, and packages.

Key Risks

Validator drift

Browser and server produce different outcomes. Prevent with shared fixtures and contract tests.

Premature normalization

Hub schemas change before tables stabilize. Preserve full JSON and use JSONB extensions.

Identity overclaim

A reviewer name is not cryptographic proof. Treat signatures as a later security layer.

Audit mutation

Editing historical events would weaken provenance. Use append-only event writes.

Scope expansion

Search, payments, tokens, and public publishing can wait until persistence works.
