Current Architecture

SourceRoot is not only a website. It is the reusable engine that allows different hubs to share one knowledge structure.

Raw Data ↓ Adapters / Connectors ↓ Nodes → Assertions → Edges → Sources → Revisions ↓ Inspector / Edge Registry / Source Registry ↓ DictionaryHub / BibleRoot / Wiki / Future Hubs
