SourceRoot

A prototype provenance engine for connecting knowledge across hubs, sources, assertions, relationships, credibility, identity, revisions, and import validation. SourceRoot turns separate knowledge systems into one inspectable, source-aware graph.

Prototype Dashboard

SourceRoot is the shared engine layer under DictionaryHub, BibleRoot, Wiki integrations, and future knowledge hubs. It separates concepts, assertions, relationships, sources, credibility metadata, identity resolution, revisions, and import validation so knowledge can be inspected, verified, connected, trusted, and reused.

Current Architecture

SourceRoot is not only a website. It is the reusable engine that allows different hubs to share one knowledge structure.

Credibility Layer

SourceRoot now includes a first-pass credibility model across connected hubs. Sources, assertions, and relationships can be classified by credibility tier, confidence, verification status, support level, interpretation level, review status, and source metadata.

Source Credibility
Sources include quality tier, publisher, license status, review status, and verification metadata.
Assertion Credibility
Claims can be marked as direct, derived, inferred, interpretive, prototype, or needs-review.
Relationship Credibility
Edges can be marked as direct, symbolic, contextual, inferred, reviewed, or needs-review.
Import Validation
Import Preview checks credibility fields before larger datasets are loaded.
